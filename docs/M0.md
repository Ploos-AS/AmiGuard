# M0 — Foundation

## Target

- Motorola 68000
- Kickstart/Workbench 1.2+
- CLI-first
- 512 KiB-friendly design
- no OS 2.x-only runtime APIs
- C89-compatible portable scanner core

## Delivered

M0 establishes the project skeleton, MIT license, 1024-byte bootblock scanner core, compact offset/pattern signature representation, DOS/unknown classification, deterministic host tests, minimal native CLI shell, and `-m68000` native build contract.

M0 intentionally contains no copied third-party antivirus database and no real malware byte patterns. Real signatures require verified sample identity, provenance, reproducible derivation and redistribution suitability.

## Acceptance

Host qualification is `make check`. Native acceptance additionally requires compilation with a suitable m68k-amigaos toolchain and a visible Kickstart 1.2 runtime test. Those native checks cannot be claimed from source inspection alone.
