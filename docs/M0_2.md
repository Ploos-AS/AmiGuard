# M0.2 — Read-only floppy bootblock acquisition

## Goal

Read the first 1024 bytes from a selected floppy drive through
`trackdisk.device` and pass them to the existing AmiGuard bootblock scanner.

## Supported CLI targets

- `DF0:`
- `DF1:`
- `DF2:`
- `DF3:`

Example:

```text
AmiGuard DF0:
```

## Safety contract

M0.2 is read-only.

The native I/O path issues only `CMD_READ` with:

- offset: `0`
- length: `1024`
- device: `trackdisk.device`
- units: `0` through `3`

No write, format, update or motor-control command is issued by AmiGuard.

## Acceptance criteria

- host scanner tests remain green,
- native build includes the trackdisk reader with `-m68000`,
- invalid drive arguments are rejected,
- a 1024-byte bootblock is read from DF0:-DF3: and scanned,
- read failures are reported without modifying media,
- visible runtime qualification is performed on an A500/68000 Kickstart 1.2 profile.

The final criterion belongs to M0.3 runtime qualification and requires a suitable emulator or real Amiga environment.
